# 校园树木 · 三维档案

一个展示校园树木形态与测量参数的三维点云平台。通过真实彩色扫描数据，浏览单棵树木的树冠、树干及空间结构。

**[访问在线平台 →](https://rnaww.github.io/campus-tree-archive/)**

## 功能

- **三维浏览**：旋转、缩放、平移点云，支持自动旋转、恢复视角与全屏查看。
- **显示设置**：切换原始颜色或高度着色，调整点大小，选择轻量或清晰模式。
- **树木检索**：按编号搜索，按扫描组别、树高范围和胸径结果筛选。
- **参数总览**：查看、排序树木参数，并下载筛选结果 CSV。
- **位置分布**：分别查看两组树木的扫描位置，点击圆点查看对应档案。
- **移动端浏览**：支持触屏操作和单棵树木链接分享。

## 数据概况

| 项目 | 数量 |
| --- | --- |
| 收录树木 | 68 棵 |
| 第 1 组 / 第 2 组 | 33 棵 / 35 棵 |
| 原始扫描点 | 17,346,793 个 |
| 可信胸径结果 | 26 棵 |
| 暂无可靠胸径结果 | 42 棵 |

树木参数包括树高、冠幅宽度与长度、平均胸径、胸径可信标记、树干顶部高度、原始点数及扫描位置。参数文件见 [All_Tree_Params.csv](public/data/All_Tree_Params.csv)。

- 网页中的胸径以厘米显示，导出 CSV 保留米单位。
- 缺失胸径显示为“暂无可靠结果”，不作为零值参与统计。
- 展示点云经过空间抽样，每棵树提供最多 5 万点的轻量模式和 20 万点的清晰模式；测量参数保留参数表中的数值。
- X/Y 为扫描坐标，未提供地理坐标系。两组位置分别展示，不对应经纬度或卫星地图。
- 精简点云用于形态展示，科研测量应使用原始数据。

## 浏览提示

在树木目录中选择编号即可查看三维点云与参数。电脑端拖动旋转、滚轮缩放、右键平移；手机端单指旋转、双指缩放和平移。

首次加载清晰模式需要下载更多点云数据，网络较慢时可切换到轻量模式。三维显示不可用时，平台仍提供真实点云预览图和树木参数。

## 技术实现

使用 TypeScript、Vite 和 Three.js 构建，作为静态网站托管于 GitHub Pages。点云、预览图及参数随站点提供，浏览无需登录。
